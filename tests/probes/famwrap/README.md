# famwrap

The height and line positions of text drawn with a font family whose lines use fonts of different heights,
with lines given by newlines and by wrapping.

Language: Lua. Build: `pdc Source famwrap.pdx`.

Notes:

- Not included (supply it to build the probe): the Nontendo-Bold and Nontendo-Light bitmap fonts (.fnt and -table-*.png) from the Playdate SDK fonts (`tests/device/assets.txt` lists the files).
