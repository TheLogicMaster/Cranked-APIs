# audlfo2

LFO behavior beyond single fresh notes: running phase across notes, retrigger and start phase, delay and ramp, arpeggios, a shared LFO, a global LFO.

Language: C. Build: `make` (with PLAYDATE_SDK_PATH set).

Notes:

- Analysis helpers: `cmp.py` (Python 3; they read the capture or log files the probe writes, given as arguments or by the names in the script).
