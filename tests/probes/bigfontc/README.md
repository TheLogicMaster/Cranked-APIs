# bigfontc

Loading a large font through the C API.

Language: C. Build: `make` (with PLAYDATE_SDK_PATH set).

Notes:

- Not included (supply it to build the probe): a large bitmap font, fonts/GreatVibes-Regular-109.fnt with fonts/GreatVibes-Regular-109-table-127-139.png. It does not ship with the SDK: it is Great Vibes (SIL Open Font License), converted to a Playdate bitmap font at 109 pixels.
