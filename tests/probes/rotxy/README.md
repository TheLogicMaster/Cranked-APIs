# rotxy

full-frame dumps of a trimmed image drawn scaled with different x and y scales.

Language: Lua. Build: `pdc Source rotxy.pdx`.

Notes:

- `Source/figure.png` is a generated 247x150 image (black, white and transparent; asymmetric, with transparent margins of different widths that pdc trims, a dithered block, solid shapes and a white disc); `tests/tools/imggen/gen.py` writes it.
