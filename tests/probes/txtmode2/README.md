# txtmode2

Black screen, Inverted draw mode, a bordered bitmap font with tracking -1 and 0; pixels as text.

Language: Lua. Build: `pdc Source txtmode2.pdx`.

Notes:

- Not included (supply it to build the probe): the namco-1x bordered bitmap font (font/namco-1x.fnt and font/namco-1x-table-9-9.png) from the SDK's Particles example.
