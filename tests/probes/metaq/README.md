# metaq

The keys, types and values of playdate.metadata, and getHeadphoneState's results.

Language: Lua. Build: `pdc Source metaq.pdx`.

Notes:

- The pdxinfo fields (author, imagePath, customKey and so on) are test data: the probe prints playdate.metadata, so expected/sim.txt echoes them. If you change a field, update the matching line in expected/sim.txt.
