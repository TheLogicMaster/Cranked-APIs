# sprrotq

Sprites with rotation drawn by sprite.update; per-frame pixel hash of the frame.

Language: Lua. Build: `pdc Source sprrotq.pdx`.

Notes:

- `Source/panel.png` is a generated 350x155 rounded panel (transparent corners, black border, white inside, off-centre black shapes); `tests/tools/imggen/gen.py` writes it.
- `Source/cursor.png` is a generated 24x24 arrow cursor (black outline, white fill, transparent background, pointing up and left); `tests/tools/imggen/gen.py` writes it.
