# luacap2

Lua synth, sample player, delay line, bitcrusher and file player timing and callbacks, captured through a C capture effect.

Language: C + Lua. Build: `make` (with PLAYDATE_SDK_PATH set).

Notes:

- Analysis helpers: `cmp.py` (Python 3; they read the capture or log files the probe writes, given as arguments or by the names in the script).
