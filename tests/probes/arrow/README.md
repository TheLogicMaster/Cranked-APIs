# arrow

A sprite made without an image that sets its image in its own update.

Language: Lua. Build: `pdc Source arrow.pdx`.

Notes:

- `Source/images/arrow-table-32-32.png` is a 7-frame 32x32 image table of a white down-pointing triangle on a transparent background, one pixel lower in each frame; `gen.py` (run in this folder) writes it.
