# sprmode

When a sprite's image draw mode change reaches the screen (a hit flash).

Language: Lua. Build: `pdc Source sprmode.pdx`.

Notes:

- `Source/assets/marks-table-24-24.png` is a generated 3-frame 24x24 image table with transparency (a black disc, a black square with a white border, a black cross; the same table as itlen); `tests/tools/imggen/gen.py` writes it.
