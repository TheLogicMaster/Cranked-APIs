# bigfont

Loading a large bitmap font from Lua and its metrics.

Language: Lua. Build: `pdc Source bigfont.pdx`.

Notes:

- Needs the GreatVibes-Regular-109 font (GreatVibes-Regular-109.fnt and GreatVibes-Regular-109-table-127-139.png) beside main.lua; it is not included and does not ship with the SDK. It is Great Vibes (SIL Open Font License), converted to a Playdate bitmap font at 109 pixels (see bigfontc).
