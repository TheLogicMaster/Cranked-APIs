# dtw

The width gfx.drawText returns against getTextSize, for single characters and short strings, in the system font (three styles) and a Bitmore font.

Language: Lua. Build: `pdc Source dtw.pdx`.

Notes:

- Not included (supply it to build the probe): the Bitmore Medieval Bold bitmap font (font-Bitmore-Medieval-Bold.fnt and font-Bitmore-Medieval-Bold-table-8-11.png), from the Playdate SDK's `Resources/Fonts/Bitmore/`; copy both files into `Source/`.
