# sprbgq

Sprites over a background drawing callback that sets and clears the clip rect; frame hash per step.

Language: Lua. Build: `pdc Source sprbgq.pdx`.

Notes:

- `Source/cursor.png` is a generated 24x24 arrow cursor (black outline, white fill, transparent background, pointing up and left); `tests/tools/imggen/gen.py` writes it.
